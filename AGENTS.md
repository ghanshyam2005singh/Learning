# AGENT.md

## Project Mission

This platform exists to help students:

- Learn from scratch
- Revise concepts
- Practice coding
- Prepare for interviews
- Build real projects
- Become industry-ready

The platform must teach deeply, not just provide information.

---

# Core Teaching Rules

## Rule 1: Never Assume Prior Knowledge

Every topic must be understandable by someone seeing it for the first time.

Always start with:

1. Definition
2. Why it exists
3. Problem it solves
4. Real-world usage
5. Syntax or structure
6. Examples
7. Common mistakes
8. Interview questions
9. Practice

---

## Rule 2: Explain Before Showing

Never dump code immediately.

Wrong:

"Here is the code."

Correct:

- What is happening?
- Why are we doing this?
- What problem does it solve?
- How should we think about it?
- Then show code.

---

## Rule 3: Teach Deeply

Avoid shallow explanations.

Every topic should include:

### Definition

Clear and precise explanation.

### Intuition

Beginner-friendly understanding.

### Why It Exists

What problem was it created to solve?

### Real World Usage

How is it used in production?

### Examples

Multiple examples.

### Common Mistakes

What beginners usually do wrong.

### Best Practices

Industry recommendations.

### Interview Questions

Beginner → Advanced.

### Revision Notes

Quick summary.

---

## Rule 4: Compare Concepts

Whenever similar concepts exist:

Explain differences.

Examples:

- let vs const
- SQL vs NoSQL
- REST vs GraphQL
- React vs Next.js
- Docker vs VM
- Monolith vs Microservices

Students should know when to use each.

---

## Rule 5: Explain Code Line By Line

Whenever code is shown:

Explain:

- Why the code exists
- What each line does
- What each variable does
- What each function does
- What output is produced

Never assume students understand code.

---

## Rule 6: Teach Implementation Thinking

Students often understand concepts but cannot write code.

Always explain:

- How to start
- What to create first
- What variables are needed
- Why certain structures are chosen
- How to convert theory into code

The goal is to teach thinking.

---

## Rule 7: Progressive Learning

Examples should progress:

Simple Example

↓

Practical Example

↓

Real Project Example

---

## Rule 8: Real Industry Context

Whenever possible explain:

- Where companies use it
- Why it matters
- Production considerations
- Performance considerations
- Security considerations
